# Tetris em Python

Um jogo de Tetris desenvolvido com Python e Pygame, com sistema de pontuação por peças colocadas, contador de linhas eliminadas, cronômetro e dificuldade progressiva.

## Funcionalidades

- Sete formatos clássicos de peças.
- Movimentação lateral e queda acelerada.
- Rotação das peças.
- Eliminação de linhas completas.
- Aumento progressivo da velocidade.
- Música em loop.
- Cronômetro e contador de peças.
- Reinício após o Game Over.

## Tecnologias

- Python 3
- Pygame

## Controles

| Tecla | Ação |
|---|---|
| ← | Mover para a esquerda |
| → | Mover para a direita |
| ↓ | Acelerar a queda |
| ↑ | Girar a peça |
| R | Reiniciar |

## Como executar

Instale o Pygame:

```bash
python3 -m pip install pygame
```

Coloque o arquivo de música na mesma pasta de `main.py` e execute:

```bash
python3 main.py
```
